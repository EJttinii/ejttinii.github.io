5-DAY OVERVIEW

4박 5일 전체 일정 한눈에 보기

일차 / 날짜 주요 권역 핵심 동선 및 일정 주요 이동 수단 도보·체력 강도
1일차 (1/13 수) 타이베이 도심 타오위안 공항 → 암바 송산 → 중정기념당 → 딘타이펑·타이베이 101 야경 공항 픽업 + 시내 택시 여유 (평지 중심)
2일차 (1/14 목) 이란현 (동남쪽) 청수지열공원(족욕) → 카발란 증류소 → 자오시 온천 가족탕 → 라오허제 야시장 단독 택시투어 (10h) + 도보 힐링 (차량·온천 위주)
3일차 (1/15 금) 타이베이 북·남 국립고궁박물원 → 쯔산위엔 정원 → 마오콩 곤돌라(찻집) → 융캉제 택시(우버) + 곤돌라 보통 (관람·다도 휴식)
4일차 (1/16 토) 북부 해안·산간 예류 지질공원(1·2구역) → 진산 라오제 점심 → 지우펀 전통 찻집 야경 · 발 마사지 단독 택시투어 (8h) 보통 (계단 생략·마사지)
5일차 (1/17 일) 송산구 일대 호텔 조식/로컬 브런치 → 펑리수·까르푸 쇼핑 → 점심 후 공항 귀국 도보·택시 + 공항 샌딩 매우 여유

겨울 타이베이 짐 싸기 4대 팁

1월 대만은 한국의 초봄·늦가을과 비슷하지만, 습도가 높고 일교차가 크며 북부 해안과 지우펀에는 비가 잦습니다.

  • 🧥
    얇은 옷 여러 겹 레이어드 긴팔 티셔츠 + 가디건 + 경량 조끼 + 방풍 점퍼 조합 추천
  • ☂️
    1인 1우산 (가벼운 접이식) 예류·지우펀·마오콩 이동 시 갑작스러운 비 대비 필수
  • 🧖
    청수지열 족욕용 개인 수건 2일차 무료 족욕탕 이용 후 발을 닦을 작은 스포츠 타월
  • 💵
    100 TWD 소액권 현금 라오허제 야시장, 로컬 조식당, 진산 노포 결제용
※ 2일차에 구매한 카발란 위스키는 기내 반입이 불가하므로 5일차 귀국 시 반드시 위탁 수하물로 부쳐야 합니다.
